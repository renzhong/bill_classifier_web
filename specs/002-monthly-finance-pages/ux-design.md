# 五类财务页面交互设计

> 设计稿口径：2026-09-24。本文描述目标体验；`ux-bills-v2.html` 与 `ux-preview.html` 使用合成数据展示交互，不代表功能已上线。

## 信息架构

主导航按用户任务组织为五个入口，不把资产和收入藏在“设置”里：

| 一级入口 | 页面与核心任务 | 现有页面的迁移关系 |
| --- | --- | --- |
| 账单 | 弹窗上传 → 解析临时表格 → 点击开始分类 → 行内修正 → 归档；同页维护分类项 | 保留旧版 `/bills/detail` 的表格骨架、筛选、下拉改类和分页；取消行选择与批量操作 |
| 分类花费 | 选择月份，查看各类别支出及对应明细 | 以 `/reports/category` 为主体；`/reports/monthly` 中账单支出信息可链接至此 |
| 每月资产 | 维护资产项及负债项，填写所选月金额；查看资产、负债、净资产 | 合并 `/settings/assets` 的录入与 `/reports/monthly` 的资产展示，建立单一“每月资产”入口；旧路径应重定向到新入口并保留月份参数 |
| 投资 | 维护投资项，填写当月买卖与现值，查看当月盈亏 | 新页面；投资现值在每月资产中只读展示 |
| 收入 | 逐笔录入发生时间与金额，查看月、年合计 | 将 `/settings/incomes` 提升为主导航“收入”；旧月度记录保留月份与旧记录标记 |

“Tag 定义/策略/Pipeline/AI 凭据”等设置未来可放在二级入口；本轮不设计规则管理页。桌面端左侧五个一级入口，移动端顶部标题与底部五入口；页面内的管理操作放在右上角。默认进入最近查看的月份，没有记录时进入当前自然月。

## 全局交互规则

1. 每个按月页面标题下方使用相同月份控件：上月、`YYYY 年 M 月`、下月。点月份打开年月选择器；URL 保留 `month=YYYY-MM`，跨页面从分类花费进入账单明细时继承月份与分类筛选。账单上传与临时预览不要求选择月份，归档查询才使用月份。未来月份可以查看与录入，界面不假设只有已结束月份可用。
2. 金额统一右对齐并显示 `¥` 与两位小数；输入框接受非负金额，负债通过“负债项”身份表示，不要求输入负号。未填写显示“待填写”，明确填入的 `¥0.00` 显示为零，二者不能混淆。
3. 自动保存会降低批量录入时的可控性。月度资产表采用逐行编辑、保存/取消；连续录入可用 Tab 跳到下一项。切换月份时有未保存改动，应提示保存、放弃或留在当前页。
4. 空状态给出当前任务的下一步；错误状态保留已有内容与输入，提供重试；加载态采用与最终布局一致的骨架。所有更新在原位置给出成功或失败反馈，不能仅依赖短暂 toast。
5. 各金额总计取当前选中月份的数据。只要存在待填写项，总计旁显示“数据未填全”，解释当前数字仅为已填写项目的合计；不把缺失项视为真实零。历史月份同理。

## 1. 账单上传、分类与归档

### 旧页面对照

| 旧版 `BillsDetail.vue` 的做法 | 处理 |
| --- | --- |
| 筛选在表格上方：月份、平台来源、分类、Tag、关键词 | 保留；平台与来源标签分开筛选，月份只用于归档查询，上传与临时批次不要求选月份 |
| 分类直接是行内下拉框 | 临时表格保留始终可见的类别下拉框；归档表格先展示结果，点击类别才进入下拉编辑 |
| 多选、批量改类、批量删除、分页与按时间查看 | 保留分页与时间信息；依本轮反馈移除首列复选框和批量选择操作 |
| 时间、金额、收/支、商户、商品、来源、标签、命中策略等信息集中在表格 | 保留密集表格的信息效率，统一调整为时间、名称、商户、收/支、来源、金额、类别、分类规则；低频字段进入行详情 |
| 上传后自动入库并分类，改规则后靠逐行重分类 | 改为解析后先停在临时表格，由用户点击“开始分类”；可修正后归档 |

**上传弹窗**：账单工作页顶部提供“上传账单”按钮，点击后打开弹窗，选择一份文件、支付宝或微信格式，以及可选的 zrz/cwx 标签（可多选）。弹窗说明支持 CSV/XLSX；无需选择月份。平台和标签在上传后固定，临时与归档表格的来源列都只读。未归档的临时批次先处理完成，再上传下一份。

**解析与分类**：解析后先显示临时表格与坏行提示；主按钮为“开始分类”。月份筛选上方只读展示一条演示规则：名称正则匹配“地铁|公交”后归到“交通”。点击开始分类后运行这条规则，类别可在表格中下拉修正。本轮不设计或开发规则管理页，也不展示规则编辑器。分类项的增删改仍从账单页短面板进入，保存后类别下拉选项同步更新。

**统一表格**：时间、名称、商户、收/支、来源、金额、类别、分类规则。临时表格的类别始终显示下拉框，方便连续修正；归档表格默认显示类别文本或“未分类”，点击该格才切换为下拉框，选择后恢复文本，失焦或按 Escape 则取消编辑。命中规则显示可读名称，人工修改后标明“人工”。来源展示上传时选择的标签及支付宝/微信平台，不提供编辑入口。临时与归档表格都没有复选框、Review 列、待审/已审状态或逐笔确认按钮。

**状态**：无上传任务时显示上传入口；解析中显示进度；失败行提供原因并保留成功行。分类运行中禁用重复触发并显示已处理笔数；规则未命中时分类为空。临时批次未归档时显著提示其不会出现在按月查询中；归档后按每笔交易时间自然归月。用户已人工修改分类的行再次执行规则时不交给 AI、也不被覆盖。

## 2. 每月分类花费

页首显示月份和本月支出总额，下方为分类列表或条形占比图：类别名、金额、占比、笔数同列，按金额从高到低排序；“未分类”单列。点分类进入账单明细，并带上当前月份和类别。图表与数值列表表达同一批数据，以数值列表为信息主载体。被排除统计的账单不进总额，可在明细筛选中单独查看。无支出时显示 `¥0.00` 与“本月暂无计入统计的支出”，允许跳转上传账单。

## 3. 每月资产汇总

**两层模型**：

- “资产项”是长期存在的命名项目，如“工资卡”“微信”“支付宝”；创建时选择资产或负债，填写名称，可选说明。名称可修改，历史金额仍挂在同一个项目 ID 下。项目停用后不再出现在未来月份的待填列表，历史月份仍可查看。删除已有历史数据的项目需要显式告知影响，常规操作优先停用。
- “月度金额”属于某资产项与某月份，只填金额，不重复创建名称。进入新月份，所有启用的手工项目自动列出“待填写”；可选“参考上月金额”逐项填入，但必须由用户确认，不自动沿用上月金额。新建资产项时可顺手填写当前月金额，也可稍后填写。

**页面布局**：页首月份控件、`新增资产项` 按钮；第一层并排展示资产总额、负债总额、净资产（资产减负债），每张卡片标明完整/未填全。第二层为“我的资产项”表，列为名称、当月金额、上月金额、变化、操作；负债项在同页单独分组。第三层为“投资估值”，逐项显示本月现值与来源“投资页”，金额只读，编辑入口跳转投资页所选月份。没有本月估值时显示“待录入”，不计入当月合计；不能再通过手工资产项为同一个投资项录入重复金额。项目行可展开历史月度金额与备注。

**编辑**：点金额进入行内金额输入，保存后即时更新三项合计。`新增资产项` 打开简短侧栏/弹窗：名称、性质（资产/负债）、可选当月金额；避免再提供固定“现金/存款/股票/基金/其他”作为必填分类，因为用户的名称就是识别资产的主要方式。资产项管理中的重命名和停用影响后续月份，保存前写清范围。

**状态**：全新用户显示“先添加一个资产项”与示例命名；已有项目但本月全未填显示每个待填行与总计“数据未填全”；全部填完后显示完成提示。投资缺估值不隐藏该投资项，且在总计旁列明缺失数量。输入校验、保存失败留在该行并保留输入值。

## 4. 投资

页首为月份控件、`新增投资项`。每项卡片显示名称、初始本金、本月买入、本月卖出、本月末现值、当月盈亏；支持展开编辑本月买卖与估值，并查看月度历史。第一月按初始本金作为上月末估值；后续按“本月末现值 − 上月末现值 − 本月买入 + 本月卖出”。盈亏卡片旁提供口径说明。缺本月估值时盈亏显示“待计算”，缺上月估值时显示“需补录上月估值”，均不显示虚假的 `¥0.00`。保存现值后，每月资产页对应行同步更新。若投资与既有手工资产项重复，创建/迁移时应提示停用重复项目。

## 5. 收入

页首显示所选月收入与所属年收入两张卡片，月份控件和 `记录收入`。明细默认按发生时间倒序，显示时间、金额、来源、备注、编辑与删除；同一来源可以有多笔。新增弹窗首屏只有必填“发生时间、金额”，来源与备注放次要位置。年收入卡片可进入按月分布。旧月度记录独立标“旧月度记录，具体日期未知”，参与对应月和年合计，但不伪装成某一天的逐笔收入；编辑旧记录时保留其月度性质，若用户填写真实日期才转为逐笔记录。删除有明确二次确认。

## 响应式与可访问性

- 桌面宽度 ≥ 1024px：固定侧导航，资产页总计三卡横排，资产/负债/投资三段表格；详情用抽屉。窄屏改为单列卡片，金额与状态始终在第一屏，编辑按钮至少 44px 点击区。
- 移动宽度 < 768px：底部五入口，月份切换固定在页面标题下，资产项按卡片排列，编辑采用底部弹层；表格的次要字段放展开详情，不要求横向滚动才能看金额。
- 标签与状态同时用文字和颜色表达；金额正负变化附文字或符号。表单有可见标签与错误提示，分类下拉、月份切换、保存可键盘操作，焦点在弹窗关闭后回到触发控件。

## 原型交互与限制

账单页第二版见 [`ux-bills-v2.html`](./ux-bills-v2.html)：弹窗演示上传、查看解析临时表格、运行默认名称正则规则、临时账单直接下拉改类别，并归档后按月查询及点按编辑。其他四类页面沿用 [`ux-preview.html`](./ux-preview.html) 的布局；其中的账单入口会打开第二版。配色统一为 [Carbon 10–30 浅色阶](./palette-options.md)。所有原型使用合成数据，数据只保存在页面内存，刷新即重置；不连接后端，也不代表真实上传、分类或迁移已经实现。
