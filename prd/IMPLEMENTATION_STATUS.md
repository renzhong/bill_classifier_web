# PRD 实施状态

更新时间：2026-09-25。PRD 记录目标；当前行为以代码、测试和 `docs/` 为准。本页只追踪规划中尚未实现的部分，不替代开发入口文档。

## 本轮已实现

- 账单页：弹窗上传、临时解析表格、显式运行一条名称正则测试规则、直接修正类别、整批归档与按月查询；临时类别直接下拉，归档类别点击后才可下拉；来源平台及上传标签不可逐笔修改。
- 分类花费：按月汇总已归档支出，可按月份与类别跳到对应账单明细。
- 每月资产汇总：可复用的命名资产项与负债项、按月独立填写金额、投资估值自动纳入、完整状态与净资产。旧资产快照回填为项目月值并保留原表只读查看。
- 投资：投资项、本金、每月买卖和估值，以及按统一公式计算的月度盈亏。
- 收入：逐笔发生时间、同月同来源多笔、编辑删除、月年合计；旧月度收入保留并计入合计。
