# PRD 06 · 账单工作页

## 用户故事

- 在同一账单工作页完成上传、查看解析后的临时表格、手动触发分类、修改分类及归档。
- 归档后按月、账单平台、来源 Tag、分类及关键词查询账单；月份由每笔交易时间决定，上传时不选月份。
- 临时表格的“类别”直接显示下拉框；归档账单通常不调整，点击类别后才变成下拉框。不逐笔点击 Review 状态。
- 在账单页增删改分类项；规则管理页与规则编辑交互本轮暂不设计。

## 页面布局

1. 顶部是账单工作区与操作：点击“上传账单”打开弹窗，选择文件、支付宝或微信格式及可选标签；解析后处理临时账单批次，再开始分类、归档。
2. 月份筛选上方仅展示一条测试规则：“名称正则匹配 `地铁|公交` → 交通”，供流程验证；不提供规则增删改或规则管理页。
3. 下方用同一张表展示临时账单或按月查询的归档账单。归档视图提供月份、平台、标签、类别、名称/商户关键词等筛选和分页。
4. 分类项可以从账单页直接新增、重命名、删除；编辑分类时仍保留表格上下文。

## 统一表格

临时和归档视图的列顺序与含义一致：

| 列 | 行内行为 |
| --- | --- |
| 时间 | 展示每笔交易时间，决定归档后的月份 |
| 名称 | 展示账单名称 |
| 商户 | 展示收款方或商户 |
| 收/支 | 展示收入、支出等交易方向 |
| 来源 | 展示支付宝/微信平台及上传时选定的标签，均不可在表格中修改 |
| 金额 | 两位小数、右对齐 |
| 类别 | 临时表格始终显示下拉框；归档表格先显示类别或“未分类”，点击后切换为下拉框 |
| 分类规则 | 显示命中的规则；人工改类后标明“人工” |

表格保留旧版的分页、筛选和行内改类。两种视图使用相同列，但类别单元格按处理阶段呈现不同状态。临时与归档视图均无首列复选框及批量选择操作；其他低频字段放在行详情，不挤占主表。无需 Review 列或逐行“标记已审”按钮。

## 行为与验收

- 解析完成先显示临时表格；未点击“开始分类”时不自动套用规则。
- 点击“开始分类”后运行默认名称正则测试规则，显示处理进度及结果；行内可直接改类别，人工结果优先。
- 同一批次确认后归档；跨月记录按各自行内时间进入相应月份。
- 从分类汇总进入账单页时，所选月份与分类筛选生效。
- 归档后表格列与临时表格一致；类别默认只展示结果，点击该格后可下拉修改，完成或取消后恢复展示。来源保持只读。
- 分页保持可用；两张表均不提供行选择框。

## 不做

- 逐笔 Review 状态或审核列。
- 本轮的规则管理页、规则编辑与批量选择操作。
- 富文本备注。
